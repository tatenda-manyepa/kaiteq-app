# KAI-TEQ V9.3 — Microsoft MSAL Recovery Patch

This patch fixes persistent `interaction_in_progress` errors after an interrupted or failed Microsoft popup login.

Changes:
- serialises MSAL initialisation so two parts of the React app cannot initialise the client concurrently;
- processes any pending redirect result during startup;
- keeps durable account/token cache in localStorage but uses sessionStorage for temporary interaction state;
- automatically detects and clears stale MSAL interaction/request keys after a failed popup;
- retries login or token popup once after stale-state cleanup;
- preserves the V9.2 dedicated popup redirect page and shared-calendar scopes.

Required Entra SPA redirect URIs remain:
- https://app.kai-teq.com
- https://app.kai-teq.com/msal-popup.html
