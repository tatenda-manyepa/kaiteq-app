# KAI-TEQ V9.2 — Microsoft 365 complete patch

This patch consolidates the Microsoft 365 work into one deployment.

## Included
- Dedicated MSAL popup callback at `/msal-popup.html` to prevent the prior timeout loop.
- Restores an existing Microsoft session after page refresh.
- Requests `User.Read`, `Calendars.ReadWrite`, and `Calendars.ReadWrite.Shared`.
- Imports events from the signed-in user's selected Outlook calendar.
- Supports importing from a shared mailbox or colleague calendar by email when Exchange sharing/delegation already permits access.
- Sends unsynced KAI-TEQ meetings to the selected personal calendar or the shared mailbox/colleague calendar entered in the Calendar panel.
- Keeps Microsoft client secrets out of the browser. No client secret is required for this SPA setup.

## Microsoft Entra redirect URIs required
Under the Single-page application platform, keep both:
- `https://app.kai-teq.com`
- `https://app.kai-teq.com/msal-popup.html`

Permissions already configured for KAI-TEQ:
- `User.Read` (Delegated)
- `Calendars.ReadWrite` (Delegated)
- `Calendars.ReadWrite.Shared` (Delegated)

## Shared calendars
The Graph permission does not create Exchange sharing rights. A user's calendar or shared mailbox calendar must already be accessible to the signed-in Microsoft 365 user. In KAI-TEQ Calendar, leave the shared mailbox field blank for your own selected calendar, or enter the shared mailbox/colleague email for a delegated calendar.
